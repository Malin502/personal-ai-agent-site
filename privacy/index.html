PRIVACY & DATA USE

Privacy Policy

Last updated: October 9, 2026

Personal AI Agent is a self-hosted personal assistant project operated for the developer's own use. The public website describes the project; it does not provide public account registration. The Google integrations described below are being developed and are not offered as a public service.

1. Google data and permissions

With explicit account authorization, the planned integration may access Gmail messages and metadata to categorize messages and prepare reply drafts; and Google Calendar events and calendar lists to review schedules and propose or create events. Permissions requested for this integration include Gmail read-only, Gmail compose, Calendar events, and Calendar list read-only. The Gmail compose scope also technically permits sending; the intended application design requires user approval before sending a message.

2. Purpose of processing

Google data is intended to be used only to fulfill the account owner's instructions, including periodic inbox review, drafting replies, event management, task extraction, and related notifications. It is not intended for advertising or sale.

3. Storage and security

The planned service runs on infrastructure controlled by the developer. OAuth credentials and refresh tokens are intended to be stored as restricted secrets, not in the public website or repository. Message and event data may be processed temporarily and limited records of task execution may be retained to avoid duplicate operations, support auditing, and present approval requests. The implementation and retention configuration must be verified before the integration becomes operational.

4. Disclosure and services

Authorized requests are sent to Google APIs to retrieve or update the account owner's data. The project may use its own AI inference service and messaging integrations to process or surface summaries and approval requests. The intended design does not sell Google user data or provide it to advertising networks. Any future external AI provider integration must be evaluated and documented before use with Google user data.

5. User control and deletion

The account owner can revoke Google access from Google Account settings. Revoking access prevents further authorized API access but does not automatically delete any previously stored local records. Local credentials and retained records can be removed by the operator from the self-hosted environment. No automated end-user deletion portal is currently provided.

6. Google API Services User Data Policy

The integration is intended to handle Google user data in accordance with the Google API Services User Data Policy, including its Limited Use requirements where applicable. Actual deployment configuration and data flows must be reviewed before enabling automated processing.

7. Changes

This policy will be updated if the project's integrations, data flows, or storage practices materially change.

8. Contact

For questions about this personal project or this policy, contact the developer via the project's GitHub issue tracker. Do not include private Google account or message data in public issues.
